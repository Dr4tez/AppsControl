# Apps Control

Приложение для штатного головного устройства (ГУ) автомобилей TENET T7.
Совместимость с ГУ других автомобилей не проверялась, но если ГУ и операционная система те же самые, то, скорее всего, совместимо.

> ⚠️ **Внимание!** Будьте осторожны при завершении и/или отключении системных приложений, а так же при изменении их разрешений — это может нарушить работу головного устройства вашего автомобиля вплоть до его полной неработоспособности.
Не включайте отображение системных приложений без необходимости. Всю ответственность за любые действия в этом приложении и за их последствия несёте только вы сами.
Автор не гарантирует работоспособность и корректную работу приложения на ГУ именно вашего автомобиля.

## Возможности

- **Завершение приложений** — список установленных приложений, завершение выбранных, быстрое завершение списком, сохранение списка для быстрого завершения с помощью отдельного ярлыка на мультимедиа экране ГУ.
- **Разрешения** — просмотр и выдача разрешений, в том числе специальных, приложениям на ГУ.
- **Автозапуск** — автоматический запуск выбранных приложений после старта ГУ: на экране или в фоне, очерёдность запуска в зависимости от настраиваемого порядка, время на запуск для каждого приложения (по умолчанию 5 секунд), настраиваемый таймаут от старта ГУ до начала автозапуска (по умолчанию 30 секунд).
- **Отключение приложений** — вкладка появляется только при включении переключателя «Разрешить отключение приложений» в настройках, отключает/включает выбранные приложения, при этом их значки пропадают/появляются на мультимедиа экране ГУ.
- **Светлая и тёмная темы**
- ### Во вкладке "Настройки"
  - **Бэкапы** - Сохранение и восстановление всех настроек Apps Control, разрешений и прочих настроек, применённых к приложениям.
  - **Меню обновления** - ручная и автоматическая проверки наличия  обновлений, установка обновлений непосредственно из приложения.
  - #### Режим ТО - возвращение экрана мультимедиа к заводскому внешнему виду:
    - При включении сначала создаётся резервная копия настроек `IT_FOR_TO-MODE_DONT_DELETE_IT-appscontrol-….json`.
    - Отключаются все сторонние приложения, кроме Apps Control и Fast Stop Apps (ярлык быстрого завершения выбранных приложений).
    - Включаются все отключенные системные приложения, за исключением пакетов com.astrob.turbodog, com.iflytek.cutefly.speechclient.hmi, com.iflytek.avatarService, com.iflytek.autofly.sceneengine, com.desaysv.vrservice и com.desaysv.vrcontrolmgr, если они есть в системе и отключены.
    - Перечисленные исключения отвечают за следующее:
      - `com.astrob.turbodog` - турбодог;
      - `com.iflytek.cutefly.speechclient.hmi` — экранный интерфейс робота;
      - `com.iflytek.avatarService` — служба анимированного аватара;
      - `com.iflytek.autofly.sceneengine` — движок предугадывания сцен;
      - `com.desaysv.vrservice` — базовая служба распознавания речи;
      - `com.desaysv.vrcontrolmgr` — менеджер выполнения голосовых команд.
    - Fast Stop Apps удаляется, значок Apps Control скрывается.
    - Режим ТО сохраняется после перезагрузки ГУ.
    - Выход из режима ТО- 20 нажатий подряд кнопки «отбой звонка» на руле (пауза между нажатиями 0,5–3 секунды).
    - При выходе из режима ТО, всё возвращается из резервной копии, созданной при активации режима, сама копия удаляется, показывается уведомление «Режим ТО отключен». Запускаются приложения из списка автозапуска.

## Требования

- Android 8.0 (API 26) или новее;
- На ГУ должен быть разблокирован ADB по сети (демон слушает `127.0.0.1`, по умолчанию порт 5555),
- Выход в интернет- для проверки наличия и установки обновлений.

## Установка и обновление

1. Скачайте `AppsControl.apk` со страницы [Releases](../../releases)
2. Скопируйте apk файл на флешку, подключите флешку к ГУ через штатный USB разъём для передачи данных и установите его через файловый менеджер, предварительно установленный на ГУ. Либо с помощью ADB AppControl.
3. Запустите **Apps Control**.
4. Если порт ADB на вашем ГУ отличается от 5555 — укажите его в настройках приложения.
5. Для проверки наличия обновлений войдите в соответствующее подменю в меню настроек и нажмите кнопку проверки наличия обновлений. Если обновление будет найдено, то нажмите на кнопку обновления. С помощью переключателя можно включить автоматическую проверку наличия обновлений при старте приложения.

## Донаты

Поддержать разработчика можно переводом (любая сумма на Ваше усмотрение) по QR коду в окне, открывающемся по нажатию кнопки "О приложении" в меню настроек. QR код ведёт на страницу перевода с помощью системы ЮMoney.
